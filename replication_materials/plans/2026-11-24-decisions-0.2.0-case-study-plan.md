# decisions 0.2.0, part 3: Gemini in the case study Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Gemini gets the treatment of gpt-6-luna in the vignette "Industrial image inspection" (D197, D302): its own description loop on each of the four datasets, the grid, the calibration, the folds and the test, and a second full run for the section "Reruns" (D311).

**Architecture:** The loop kit (`data-raw/study_again/loop/`) and `data-raw/study_again.R` get a model setting, so that Gemini has its own sandbox, files, purpose labels and work folder, and the files of gpt-6-luna stay as they are. `case_save()` gets a path that saves a model before its test. The vignette reads every Gemini row from `inst/extdata/study_again.rds`.

**Tech Stack:** R, decisions with `decider_gemini()`, the Claude Code CLI (`claude -p`, model `claude-opus-5-5`, the flags of `run_loop.sh`), the study's audit code (`R/fair_loop.R`).

**Spec:** `replication_materials/plans/2026-11-24-decisions-0.2.0-design.md` section 3 (D313); D197, D213, D301, D311.

Paths: `decisions/`, `study/` as in part 2. The map of the current pipeline is in the report of 2026-11-24 (study_again.R lines 82, 88, 91-98, 264-294, 373-379, 457, 508, 786-836, 915-1088, 1106-1111; loop kit files).

Sandbox root `C:/Users/megahefm/decisions-gemini-loops`, outside Dropbox. The transcripts are kept (the gpt-6-luna transcripts are lost).
