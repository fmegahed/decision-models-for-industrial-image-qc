**Spec:** `replication_materials/plans/2026-11-24-decisions-0.2.0-design.md` (approved, D313), sections 1, 2 and 5. Vignettes and the release are later plans.

## Global Constraints

- Gemini: base URL `https://generativelanguage.googleapis.com`, path `v1beta/decisions`, default model `gemini-decision-1`, key `GEMINI_API_KEY` in the header `x-goog-api-key` (redacted), provider name "Google Gemini".
- Venn: default base URL `http://127.0.0.1:8000`, path `api/alpha/decisions`, default model `venn-1`, no key, provider name "Venn"; image requests carry `X-Venn-Experimental: media`.
- "No change to the request bodies of the existing providers. The saved fixtures of 0.1.x must still pass."
- Paid calls: only Task 1 (Gemini, budget row of D301); each one logged in `study/replication_materials/calls/gemini-calls.csv`. Venn calls are local and free.
- No network call in tests (live tests only behind `DECISIONS_LIVE_TESTS` / `DECISIONS_LIVE_LOCAL`).
- Never print or commit a key. The probe reads `GEMINI_API_KEY` with `readRenviron("study/.env")`.
- Work on the branch `deciders-gemini-venn` of decisions, from `main` after the merge of 0.1.1. Commits end with the two trailer lines of the session.
- Style: httr2, purrr, native pipe, `pkg::fun`, roxygen markdown; internal functions get `@noRd`.

## Review Focus

1. A Gemini choice whose answer has no description (`NA`) must send `""`, not the answer name and not `null`. Task 2 tests it.
2. A Gemini question name with a dot (`"is.refund"`, legal in R) must stop before any request with a message that names the rule, and send nothing. Task 2 tests it.
3. A Gemini request with references and a text: the text block comes after the inspected image, and every text block ends with `"\n"`. Task 2 tests the order and the newlines.
4. Venn with a text and an image in the same call, or with references, must stop before any request; Venn would ignore the text without an error. Task 3 tests both.
5. Venn reports `input_tokens: 0` and `cost: 0`; the output of `decide()` must show `NA`, not 0, so that a summary of cost does not read "free" as "measured". Task 3 tests it.
